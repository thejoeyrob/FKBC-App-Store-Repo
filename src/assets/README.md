# Asset boundary

This slice draws original temporary debug geometry in Phaser and synthesizes impact audio.
Place future original fighter, stage, and audio assets here. No previous PWA, downloaded
fighter artwork, or final character art is used. Joe is the only playable roster entry.

Artist handoff: [ART_BRIEF.md](../../docs/ART_BRIEF.md), with a prioritized
[asset checklist](../../docs/ASSET_CHECKLIST.csv) and technical frame/stage guides.
These describe future deliveries; no final fighter art is generated or loaded yet.
